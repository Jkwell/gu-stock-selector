## 二、核心用法：每天尾盘怎么做（30 秒流程）

```
第一步  打开「🌡️ 市场」看情绪
        🔥 情绪火热 → 今天可以做
        😐 情绪一般 → 谨慎，小仓位
        🧊 情绪冰点 → 空仓观望，别硬选

第二步  看「🔥 热点题材」榜
        记住今天最强的主线（比如光模块、算力）

第三步  去「🎯 今日推荐」
        选策略 → 生成 → 得到 4 只票 + 买卖点

第四步  对照买卖点操作：
        - 价格在「买入区间」→ 分批买入
        - 到「止盈价」→ 卖出落袋
        - 跌破「止损价」→ 坚决离场

第五步  推荐会自动加入「👁️ 监控」
        每天盯盘，触发关键价位会自动闪烁提醒

第六步  （可选）在「💰 持仓」记录买入，自动算盈亏
        过几天看「📋 复盘」，检验推荐质量
```

## 三、7 个策略模板（选哪个？）

| 策略 | 特点 | 适合谁 | 风险 |
|------|------|--------|------|
| **📈 温和放量** ⭐推荐 | 量比1.2~5 + 换手5~15% + 上升趋势，不追涨停 | 稳健短线、回踩低吸 | 低 |
| **🔥 题材龙头** | 从当日最强概念题材选领涨股（光模块/算力龙头） | 想抓风口主线 | 中高 |
| **🔥 强势领涨** | 连板 + 3日爆发力 + 创新高，追最强势 | 激进打板选手 | 高 |
| **⚖️ 均衡配置** | 技术/基本面/资金各维度均衡 | 长线、稳健 | 低 |
| **💎 价值精选** | 低估值 + 高盈利，捡便宜货 | 价值投资 | 低 |
| **🚀 成长先锋** | 高成长（增速快的公司） | 中长线成长股 | 中 |
| **📈 动量追击** | 纯技术面趋势，追涨不追跌 | 波段操作 | 中高 |

**新手推荐**：先用「📈 温和放量」——它是博主四步法的完整实现，选出来的票又温和放量、又是上升趋势、还带前高前低买卖点，最安全。

## 四、选股用的因子是什么意思

### 技术面（看价格和成交）
| 因子 | 含义 | 通俗解释 |
|------|------|---------|
| 趋势强度 | 股价 vs 20/60日均线 | 股价越在均线上方，越强势 |
| MACD 动量 | MACD 金叉/死叉 | 红柱变大=多方强，绿柱=空方 |
| RSI 状态 | 14日强弱指标 | 过高(>70)=涨太多小心，过低(<30)=超跌 |
| 成交量异动 | 今天量比平时大多少 | 温和放量好，天量危险 |
| 动量(1月/3月) | 近1月/3月涨幅 | 涨得多=强，涨得少=弱 |
| 短期反转 | 近5日跌了多少 | 超跌反弹逻辑 |
| 低波动 | 股价波动幅度 | 波动越小越稳 |
| 3日爆发力 | 近3天涨了多少 | 短线龙头特征 |
| 创新高 | 是否突破前高 | 突破新高=强势 |
| 连板高度 | 连续几个涨停 | 连板越多越妖，2-4板是黄金期 |

### 基本面（看公司好不好）
| 因子 | 含义 | 通俗解释 |
|------|------|---------|
| 估值水平 | PE 贵不贵（行业内比较） | 越低越便宜 |
| 盈利能力 | ROE 赚钱效率 | 越高越好 |
| 成长性 | 利润增速 | 增长越快越好 |

### 资金面
| 因子 | 含义 |
|------|------|
| 主力净流入 | 大资金今天净买入多少 |

## 五、买卖点怎么读

每只推荐的票会给出三个价位：

```
买入区间：支撑位 ~ 现价之间
  价格跌到这里 → 分批买入（越接近支撑越划算）
  价格高于区间 → 别追，等回调

止盈目标：涨到这里 → 卖出落袋
  参考前期高点和 +5%

止损价：跌破这里 → 坚决离场
  约 -8%，控制单票最大亏损
```

**铁律：跌破止损不犹豫。** 亏损 8% 走人，比死扛套牢 30% 好太多。

## 五之二、自己查一只票怎么看（🔍 个股分析）

除了工具帮你选，你还可以自己输代码查任意一只票（比如别人推荐给你的）：

```
第一步  打开「🔍 个股分析」→ 输入股票名称（中文，如"茅台"）或 6 位代码 → 开始分析
        输入中文会实时弹出联想下拉，多点几下也能搜到（如 600519、贵州茅台）
        搜到多只同名/含关键字时（如"平安"），点下拉里那只正确的再分析

第二步  看顶部结论横幅：
        ✅ 适合买入   → 技术面健康，可按买点分批低吸
        ⏳ 观望等待   → 有积极信号但还不够，等回踩支撑 / MACD 翻红
        ❌ 不建议买入  → 空头/超买/高位连板/一字板，先别碰

第三步  看「买点 / 卖点」三档价位：
        买入区间 / 止盈目标（卖点）/ 止损价（卖点）

第四步  看「技术面逐项检查」：趋势、MACD、RSI、量能、买点可及、
        风险回报比各打了勾没，哪项不过一目了然

第五步  满意的话点「👁️ 加入监控」，之后自动盯盘提醒
```

**注意**：⚠️ 一字板买不进、🔴 高位风险（5 连板+）会直接判"不适合买"；大盘情绪 🧊 冰点时，再好的一只票也会降级为"观望"——先看大盘再做个股。

## 六、市场情绪怎么用

```
🔥 情绪火热（温度≥70，涨停多）：可以做，追强
😐 情绪一般：谨慎，控制仓位
🧊 情绪冰点（温度<40，涨停极少）：空仓，等情绪回暖
```

**这是最重要的择时信号**——熊市/冰点里再好的选股也亏钱。冰点时别硬做。

## 八、AI 研报怎么用（可选，需 LLM API Key）

多智能体深度分析：输入一只票，后台由 7 个 AI 分析师（技术 / 情绪 / 新闻 / 基本面 / 政策 / 游资 / 解禁）各写一份报告 → 多空辩论 → 风控评估 → 投资经理给出 **Buy / 偏多 / Hold / 偏空 / Sell** 五档评级。

**首次使用先配置：**
```bash
# 1. 装 Python 依赖（一次性，约几分钟）
cd d:/Agent/tradingAgents-astock && pip install -e .
cd d:/Agent/gu && pip install -r ai-server/requirements.txt

# 2. 在 ai-server/.env 填 DEEPSEEK_API_KEY（platform.deepseek.com 申请）

# 3. 启动 AI 服务（与前端分开的终端）
npm run ai-server
```

**用法：** 打开「🤖 AI 研报」→ 输入 6 位代码（或点「今日推荐」快捷标签）→ 开始分析 → 实时看 12 阶段进度 → 查看完整报告与评级。历史研报本地保存，可随时回看、删除。

**注意：**
- 每次分析约 1-3 分钟、消耗 30-50 次 LLM 调用（约几块钱），走你自己的 DeepSeek 账户计费
- 评级来自 LLM 对软信息（消息面 / 政策 / 资金博弈）的研判，与「今日推荐」的量化打分互补，两者均不构成投资建议
- 后端需保持运行；服务重启后任务丢失，但已生成的研报保存在浏览器本地

## 九、重要风险提示（必读）

1. **工具是辅助，不是荐股**。所有买卖点是基于技术面的概率性参考，**不构成投资建议**。
2. **涨停板追高风险极大**。龙头策略选出的涨停股是用来"看方向"的，建议等回调到支撑位再低吸，而不是追涨停当天买。
3. **情绪冰点不操作**。🧊 时管住手。
4. **严格止损**。单票亏损 8% 坚决走，这是你活下来的关键。
5. **别重仓单票**。4 只票建议每只仓位均分（各 25%），分散风险。
6. **数据偶发延迟**。东财接口偶尔限流（工具已自动降级到新浪），限流时概念题材数据可能暂时缺失，稍后自动恢复。

## 十、常见问题

**Q: 为什么选的票有的买不进？**
A: 一字板（开盘就涨停封死）标了"⚠️一字板买不进"，这种别追。

**Q: 为什么我看的板块和它选的不一样？**
A: 工具用"概念题材"（光模块/算力）比"行业"（通信设备/造纸）更贴近短线，默认显示概念榜。

**Q: 今天情绪冰点，还能用吗？**
A: 可以看，但建议空仓。工具会在冰点时提示你。

**Q: 策略之间怎么切换？**
A: 今日推荐页顶部有策略按钮，点一下切换；也可以选股页自己调因子权重。

**Q: 数据准不准？**
A: 行情/分时/买卖点来自腾讯实时接口，很准；财务数据来自东财，按季更新。
