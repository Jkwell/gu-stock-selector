1

打开Vercel并登录

点击下面的按钮打开Vercel官网：

🌐 打开 Vercel.com
💡 提示： 点击后会在新标签页打开。请用GitHub账号登录（选择 "Continue with GitHub"）。
2

导入项目

登录后，在Vercel Dashboard：

  • 点击右上角 "Add New..." → "Project"
  • 找到仓库 "gu-stock-selector"
  • 点击 "Import" 按钮
💡 看不到仓库？ 点击 "Adjust GitHub App Permissions" → 勾选你的仓库 → 保存
3

确认配置

Vercel会自动检测配置，确认以下设置：

Framework Preset: Vite Build Command: npm run build Output Directory: dist Install Command: npm install

通常不需要修改，直接下一步。

4

开始部署

点击页面底部的蓝色大按钮：

然后等待2-3分钟，Vercel会自动：

  • 安装依赖（npm install）
  • 构建项目（npm run build）
  • 部署到全球CDN
⏳ 耐心等待： 首次部署需要2-3分钟，你会看到实时日志输出。
5

获取URL并测试

部署成功后，Vercel会显示：

🎉 Congratulations! Your project is live at: https://gu-stock-selector.vercel.app

点击这个URL，测试功能：

  • 页面能正常打开
  • 点击"今日推荐"
  • 选择策略，点击"生成推荐"
  • 能看到推荐的股票
🔍 如何检查： 按F12打开控制台，看是否有红色错误。Network标签查看 /api/proxy 请求是否成功（Status: 200）。
