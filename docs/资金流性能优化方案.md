# 📊 资金流性能优化方案

## 🐛 问题诊断

### 当前问题

**线上拉取资金流非常慢**，主要原因：

1. **东财JSONP限流**：
   - 代码强制每个请求间隔 ≥ 300ms（`EM_JSONP_MIN_INTERVAL_MS = 300`）
   - 防止被东财服务器封禁

2. **串行队列**：
   - 所有资金流请求通过 `queueEastmoneyJsonp()` 串行执行
   - 无法并发

3. **时间计算**：
   ```
   候选池200只股票 × 300ms/只 = 60秒
   候选池500只股票 × 300ms/只 = 150秒（2.5分钟）
   ```

### 代码位置

**src/data/api.ts**：

```typescript
// 第40行：限流配置
const EM_JSONP_MIN_INTERVAL_MS = 300  // ⚠️ 每个请求最少间隔300ms

// 第78-91行：串行队列
function queueEastmoneyJsonp<T>(request: () => Promise<T>): Promise<T> {
  const run = async () => {
    const wait = Math.max(0, nextEastmoneyJsonpAt - Date.now())
    if (wait > 0) await delay(wait)  // ⚠️ 强制等待
    nextEastmoneyJsonpAt = Date.now() + EM_JSONP_MIN_INTERVAL_MS
    return request()
  }
  // ⚠️ 串行队列，无法并发
  const result = eastmoneyJsonpQueue.then(run, run)
  eastmoneyJsonpQueue = result.then(() => undefined, () => undefined)
  return result
}
```

### 方案二：批量接口优化 ⭐⭐（推荐）

**思路**：使用东财的批量接口，一次请求多只股票

**新增接口**：
```typescript
// src/data/api.ts

/**
 * 批量获取资金流（一次最多50只）
 * 减少请求次数，提升性能
 */
export async function fetchMoneyFlowBatch(
  stocks: Array<{ market: StockInfo['market']; code: string }>
): Promise<Map<string, MoneyFlow | null>> {
  const result = new Map<string, MoneyFlow | null>()
  
  // 每批最多50只（东财限制）
  const batchSize = 50
  for (let i = 0; i < stocks.length; i += batchSize) {
    const batch = stocks.slice(i, i + batchSize)
    const secids = batch.map(s => secidOf(s.market, s.code)).join(',')
    
    const query = new URLSearchParams({
      secid: secids,
      lmt: '1',
      klt: '101',
      fields1: 'f1,f2,f3,f7',
      fields2: 'f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f62,f63,f64,f65',
    })
    
    try {
      const data = await fetchEastmoneyJsonp<any>(EM_FFLOW, query)
      // 解析批量结果
      const items = data.data?.diff ?? []
      for (const item of items) {
        const code = item.f12 // 股票代码
        result.set(code, {
          code,
          date: item.f51 ?? '',
          mainNetInflow: Number(item.f52 ?? 0),
          bigNetInflow: Number(item.f55 ?? 0),
          superNetInflow: Number(item.f56 ?? 0),
        })
      }
    } catch {
      // 失败时标记为null
      batch.forEach(s => result.set(s.code, null))
    }
    
    // 批次间仍需等待300ms
    if (i + batchSize < stocks.length) {
      await delay(300)
    }
  }
  
  return result
}
```

**修改调用**：`src/data/pipeline.ts`

### 方案三：使用缓存 + 后台预加载 ⭐⭐⭐（最佳）

**思路**：
1. 用户打开页面时，后台预加载常用股票的资金流
2. 用户选股时，大部分数据已在缓存中

**新增服务**：
```typescript
// src/services/preload.ts

/**
 * 后台预加载服务
 * 在用户空闲时预加载热门股票的资金流
 */
class PreloadService {
  private isPreloading = false
  
  /**
   * 预加载热门股票资金流
   * @param topN 预加载前N只热门股票（按成交额）
   */
  async preloadPopularStocks(topN = 300) {
    if (this.isPreloading) return
    this.isPreloading = true
    
    try {
      // 获取热门股票列表（按成交额排序）
      const stocks = await fetchMarketStocks()
      const popular = stocks
        .sort((a, b) => (b.amount ?? 0) - (a.amount ?? 0))
        .slice(0, topN)
      
      console.log(`🔄 后台预加载 ${popular.length} 只热门股票资金流...`)
      
      // 批量加载（50只/批）
      const batchSize = 50
      for (let i = 0; i < popular.length; i += batchSize) {
        const batch = popular.slice(i, i + batchSize)
        const moneyFlowMap = await fetchMoneyFlowBatch(
          batch.map(s => ({ market: s.market, code: s.code }))
        )
        
        // 写入缓存
        for (const [code, mf] of moneyFlowMap.entries()) {
          if (mf) await moneyflowCache.set(code, mf)
        }
        
        console.log(`✅ 已预加载 ${i + batch.length}/${popular.length}`)
        
        // 批次间等待（后台任务，可以慢一点）
        if (i + batchSize < popular.length) {
          await delay(500)
        }
      }
      
      console.log(`✅ 后台预加载完成！`)
    } finally {
      this.isPreloading = false
    }
  }
  
  /**
   * 在页面空闲时启动预加载
   */
  startIdlePreload() {
    if (typeof requestIdleCallback !== 'undefined') {
      requestIdleCallback(() => {
        this.preloadPopularStocks(300)
      }, { timeout: 5000 })
    } else {
      // 降级：5秒后开始
      setTimeout(() => {
        this.preloadPopularStocks(300)
      }, 5000)
    }
  }
}

export const preloadService = new PreloadService()
```

**使用**：`src/App.tsx`

```typescript
export default function App() {
  useEffect(() => {
    // 页面加载后，后台预加载热门股票资金流
    preloadService.startIdlePreload()
  }, [])
  
  // ...
}
```

**效果**：

**优点**：

- ✅ 后续选股极快

**缺点**：

## 📝 代码实现示例

### 批量接口完整实现

创建新文件 `src/data/api-batch.ts`：

```typescript
import { fetchEastmoneyJsonp, delay, secidOf } from './api'
import type { MoneyFlow, StockInfo } from '../types'

const EM_FFLOW = 'https://push2.eastmoney.com/api/qt/stock/fflow/kline/get'

/**
 * 批量获取资金流（每批最多50只）
 */
export async function fetchMoneyFlowBatch(
  stocks: Array<{ market: StockInfo['market']; code: string }>
): Promise<Map<string, MoneyFlow | null>> {
  const result = new Map<string, MoneyFlow | null>()
  const batchSize = 50
  
  for (let i = 0; i < stocks.length; i += batchSize) {
    const batch = stocks.slice(i, i + batchSize)
    
    try {
      // 构造批量secid参数
      const secids = batch.map(s => secidOf(s.market, s.code)).join(',')
      
      const query = new URLSearchParams({
        secid: secids,
        lmt: '1',
        klt: '101',
        fields1: 'f1,f2,f3,f7',
        fields2: 'f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f62,f63,f64,f65',
      })
      
      const data = await fetchEastmoneyJsonp<any>(EM_FFLOW, query)
      
      // 解析批量结果
      const items = Array.isArray(data?.data?.diff) ? data.data.diff : []
      
      for (const item of items) {
        const code = String(item.f12 ?? '')
        if (!code) continue
        
        result.set(code, {
          code,
          date: String(item.f51 ?? ''),
          mainNetInflow: Number(item.f52 ?? 0),
          bigNetInflow: Number(item.f55 ?? 0),
          superNetInflow: Number(item.f56 ?? 0),
        })
      }
    } catch (error) {
      console.warn(`批量获取资金流失败（批次 ${i / batchSize + 1}）:`, error)
      // 失败时，该批次所有股票标记为null
      batch.forEach(s => result.set(s.code, null))
    }
    
    // 批次间等待300ms（避免限流）
    if (i + batchSize < stocks.length) {
      await delay(300)
    }
  }
  
  return result
}
```
