✅ Netlify

注册即可使用
5分钟完成部署

1

打开Netlify并登录

点击下面的按钮打开Netlify官网：

🌐 打开 Netlify.com
💡 提示： 选择 "Sign up with GitHub" 用GitHub账号登录，一键授权即可！
2

添加新网站

登录后，在Netlify Dashboard：

  • 点击 "Add new site" 或 "Import from Git"
  • 选择 "GitHub"
  • 授权Netlify访问你的仓库
💡 第一次使用： 需要授权Netlify访问GitHub，点击 "Authorize Netlify" 即可。
3

选择仓库

在仓库列表中找到：

gu-stock-selector

点击它！

💡 看不到仓库？ 点击 "Configure the Netlify app on GitHub" → 选择你的仓库 → 保存
4

配置部署设置

Netlify会自动检测配置，确认以下设置：

Base directory: (留空) Build command: npm run build Publish directory: dist Functions directory: netlify/functions

⚠️ 重要： Functions directory 必须填写：netlify/functions

💡 提示： 这个配置让Netlify知道我们的代理函数在哪里。
5

开始部署

配置完成后，点击：

然后等待2-3分钟，Netlify会自动：

  • 克隆你的仓库
  • 安装依赖（npm install）
  • 构建项目（npm run build）
  • 部署Serverless Functions
  • 发布到全球CDN
6

获取URL并测试

部署成功后，Netlify会显示：

🎉 Site is live! https://random-name-12345.netlify.app

点击这个URL，测试功能：

  • 页面能正常打开
  • 点击"今日推荐"
  • 选择策略，点击"生成推荐"
  • 能看到推荐的股票 ✅
🔍 如何检查： 按F12打开控制台，Network标签查看 /.netlify/functions/proxy 请求是否成功（Status: 200）。
7

自定义域名（可选）

Netlify会自动生成一个随机域名，你可以改成好记的：

  • 在Site settings → Domain management
  • 点击 "Options" → "Edit site name"
  • 改成：gu-stock-selector.netlify.app
💡 提示： 域名必须全球唯一，如果被占用就换一个。
